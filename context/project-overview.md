# Project Overview
## О проекте
Одностраничный тест из 10 вопросов. Пользователь проходит тест, отвечая на вопросы, и по итогу получает один из четырёх типов личности:

А → Срывщик

Б → Уставший

В → Теоретик

Г → Перфекционист

Побеждает тот тип, ответов за который больше всего. Результат показывается пользователю сразу после завершения теста.

## Какую задачу решает
Люди часто не понимают, почему у них не получается похудеть, почему они срываются или постоянно откладывают. Тест помогает за несколько минут определить свой тип и понять, что именно мешает двигаться вперёд.

Тест не требует регистрации, не собирает персональные данные и работает полностью на клиенте — пользователь просто отвечает на 10 вопросов и получает результат.

### Стартовый компонент

Лого 
Название бренда

### Компонент самого теста
На странице друг под другом отображаются сразу все вопросы

У каждого вопроса есть номер, который является картинкой question-[номер].png. На заднем фоне номера желтый круг.
К каждому вопросу 4 варианта ответа, каждый соответствует одной букве (А, Б, В или Г).

Пользователь выбирает один вариант

Между вопросами есть картинки с женщинами.

После отметки всех вопросов можно нажать кнопку "Получить результат теста" и будет переход на страницу с результатом.

### Экран результата

Показывается соответствующая картинка с названием (картинка с женщиной).

Показывается заголовок и описание.

## Критерии успеха
Пользователь проходит тест за пару минут без инструкций

Все 10 вопросов отображаются корректно, по одному за раз

Подсчёт типов работает правильно — побеждает тот, которого больше

Экран результата показывает верный тип, описание и картинку

Вёрстка соответствует макету context/designs/test-page.png

Шрифты и цвета соответствуют context/designs/colors-fonts.md

Изображения с женщинами заменены на 1.png

Enum с названиями изображений позволяет легко подменить их на целевые

Интерфейс визуально консистентен и адаптивен
